# คู่มือใช้งาน gotzji v1.0.0 (ภาษาไทย)

คู่มือนี้อัปเดตตาม source `v1.0.0`; gotzji ยังไม่มีรุ่นที่เผยแพร่อย่างเป็นทางการ

gotzji เป็นแอปบน Windows ที่ให้ ChatGPT สั่งงานบนเครื่องได้ โดย Grace ควบคุมการทำงานทุกขั้น ชุดนี้ยังอยู่ระหว่างพัฒนาและทดสอบไปสู่ v1.0.0 ดาวน์โหลดต้นฉบับได้จาก [คลัง gotzji](https://github.com/Scotty20761/gotzji) เมื่อเผยแพร่โค้ดแล้ว

## เริ่มต้นจากแอป

1. เปิด gotzji แล้วตรวจว่าระบบควบคุมงานพร้อมใช้งาน
2. เพิ่มโครงการและเลือกโฟลเดอร์ที่ต้องการทำงาน
3. เลือกเครื่องมือ กรอกเป้าหมาย แล้วเริ่มงาน
4. ใช้หมายเลขงานเดิมเพื่อดูความคืบหน้า ผล บันทึก หรือยกเลิกงานนั้น

การปิดหน้าต่างไม่ได้แปลว่างานหยุด ส่วนงานที่ใช้ไฟล์หรือโปรแกรมร่วมกันจะรอคิว หากยังยืนยันไม่ได้ว่าโปรแกรมเดิมหยุดแล้ว ระบบจะให้ตรวจสอบก่อนทำซ้ำ

## เชื่อมกับ ChatGPT

สร้างช่องเชื่อมต่อใหม่สำหรับ gotzji ใน OpenAI Platform ใช้คีย์สำหรับการเชื่อมต่อที่มีสิทธิ์ Tunnels Read + Use แล้วกรอกในแผงเชื่อมต่อของแอปโดยตรง ห้ามส่งคีย์ในแชท แอปเก็บคีย์ด้วยการป้องกันของบัญชี Windows นี้

เปิดการเชื่อมต่อ แล้วเพิ่ม gotzji ใน ChatGPT ตามสิทธิ์ของบัญชีและพื้นที่ใช้งาน การเชื่อมต่อสำเร็จต้องทดลองเรียกเครื่องมือจริงและเห็นหมายเลขงานเดียวกับในแอป ทั้ง Plus และ Pro ต้องมีผลทดสอบแยกกัน

## เมื่อทำงานต่อไม่ได้

- ไฟล์เปลี่ยนไป: อ่านไฟล์ล่าสุดแล้วเตรียมคำสั่งใหม่
- โควตา Grace หมด: ดูเวลาที่ลองใหม่ได้ งานเดิมยังอยู่ และไม่มีการเปลี่ยนไปใช้ API เสียเงินอัตโนมัติ
- เน็ตหรือหน้า ChatGPT หลุด: กลับมาเลือกงานเดิมก่อนเริ่มคำสั่งซ้ำ
- เปิดเครื่องใหม่: ตรวจงานค้างและผลเดิมก่อนทำต่อ การกู้หลังเปิดเครื่องยังต้องผ่านการทดสอบรุ่นติดตั้งจริง
- โปรแกรม Office/CAD ไม่พร้อม: ตรวจโปรแกรมและรุ่นที่รองรับในแอปก่อนเริ่มงาน

## ติดตั้งและเปลี่ยนรุ่น

ยังไม่มีตัวติดตั้ง gotzji ที่ประกาศพร้อมใช้อย่างเป็นทางการ รุ่นเป้าหมายจะไม่มีลายเซ็นผู้เผยแพร่ ต้องตรวจ SHA-256 กับประกาศรุ่นก่อนติดตั้ง และเปลี่ยนรุ่นด้วยตนเอง ไม่มีการอัปเดตอัตโนมัติ

ไฟล์ทดสอบในเครื่องที่อาจสร้างขึ้นคือ `gotzji-Setup-1.0.0.exe` และ `gotzji-Portable-1.0.0.exe` ชื่อไฟล์ไม่ได้ยืนยันว่าทดสอบครบหรือเผยแพร่แล้ว Office และ CAD ต้องติดตั้งและมีสิทธิ์ใช้งานแยกต่างหาก

คู่มือต้นฉบับ lnwjud เก็บไว้ใน docs/upstream/ เพื่ออ้างอิงประวัติ
